# Sales Analysis Dashboard – Power BI

This project presents a business sales analysis dashboard created using Power BI.

The dashboard provides insights into:
- Sales performance
- Profit analysis
- Product comparison
- Regional sales trends

Tools Used:
- Microsoft Power BI
- Data Visualization
- Business Analytics

Key Features:
- Interactive dashboard
- KPI indicators
- Visual comparison of sales and profit
